# HTX 复杂运营视觉

用于复杂长图、规则表格、多模块活动、机构/VIP、双语海报、模板复刻和可编辑 SVG。

## 流程

1. 逐字锁定用户或源文档内容，不增写、不润色。
2. 按内容选择 Hero、卡片、表格和底部结构；内容决定画布高度，不套固定高区块。
3. 使用 Skill 字体与品牌资产完成 HTML/CSS 排版；复杂长图默认输出最终 PNG。
4. 检查一次最终图；发现裁切、碰撞、异常换行或留白失衡时，只做一次针对性修正。

## 内容锁定

- 不自行添加 CTA、二维码、链接、角标、时间、免责声明、说明或装饰。
- 用户明确要求的视觉改写只改变表现，不扩写业务事实。
- 用户稍后自行贴图时只留构图空间，不画可见占位框或提示文字。
- 未指定语言时使用源文档第一语言，不自行合并双语。

## 品牌基础

- 品牌蓝 `#0066FF`；正文黑 `#000000`；白色 `#FFFFFF`。
- 正文卡片 `#F6F6F6`；表头 `#F5F7FA`；表格线 `#E8E8E8`。
- 礼物序号标签背景 `#EBFF3A`，文字纯黑。
- VIP 金 `#C9A84C`，只用于明确的机构/VIP 金色体系。
- 只用 400 / 500 / 700 字重；禁用 800、900、black 和斜体。
- 字体使用 `assets/fonts/` 内 HarmonyOS Sans SC 与 Urbanist；Logo 使用 Skill 官方资产。

## Hero

- 使用柔和蓝白渐变，由蓝自然过渡到白；不加网格、噪点或未提供装饰。
- 主标题、时间和辅助文字均用纯黑；时间放在主标题下方。
- 配图与标题采用左右构图；配图可稍靠下并适度放大，不强制水平中轴。
- Hero 高度由内容决定。1080px 长图通常从 450–500px 调整，正文应自然衔接，不得用固定高度制造大块空白；也不得为追求紧凑造成拥挤。
- 1080px 画布 Logo 为 100×100，距上、右各 60px；左右安全边距默认 80px，硬下限 64px。

## 正文与标签

- 外层保持白色；信息模块默认使用独立 `#F6F6F6` 圆角卡片，1080px 画布圆角约 28–32px。
- 卡片高度、内边距和行高按真实内容收紧，不保留无意义固定留白。
- 卡片或表格已有边界时，不再添加横向分割线；有序号标签时不再添加竖线。
- 表格内部保持白色；短内容尽量单行，必须换行时按完整语义换行。
- 序号可套用礼物标签模式：标签只放“1 / 2 / 3”或“礼一 / 礼二 / 礼三”，后方标题保持黑色；不使用圆形描边、分隔点或蓝色标题。
- 标签使用 `#EBFF3A` 圆角矩形；1080px 中文稿可从 32px、内边距 12px 20px、圆角 16px 开始调整。

## 底部

- 底部必须保持白色；禁止蓝色底栏、蓝色页脚或独立蓝色免责声明区。
- 二维码只在源文档包含或用户明确要求时出现；未提供二维码时可按用户要求使用线框占位。
- CTA 存在时使用品牌蓝圆角矩形、白字、圆角约 16px，宽度不得越过安全边距；不使用胶囊形。
- 底部文案与二维码同时出现时组成左右组合，视觉居中即可，不强制精确水平对齐。

## 输出

- PNG：使用 HTML/CSS 和 Skill 字体渲染，画布与导出 viewport 一致；写出后检查真实像素、安全区和文字溢出。
- 可编辑 SVG：文字用独立 `<text>`，形状用 `<rect>/<line>/<path>`，渐变用 `<linearGradient>`，Logo 与配图区分层。
- SVG 禁止嵌入整张 PNG 或用 `foreignObject` 伪装可编辑结构；用 `xmllint --noout` 验证并确认内容可见。

## 禁止项

- 禁止擅自补内容、二维码或按钮；禁止阴影、霓虹、深色大背景、页脚色条、卡片渐变和无依据网格。
- 禁止对用户素材整体调色、曝光、饱和度、色相或滤镜处理。
- 禁止同时堆叠卡片、表格边界、分割线和竖线制造重复层级。

## 交付前检查

- 文案逐字完整；Logo、字体、颜色、安全区正确。
- Hero 与正文距离自然，卡片行高紧凑，没有大块空白或拥挤碰撞。
- 标签为 `#EBFF3A` 圆角矩形，标题纯黑；底部保持白色。
- 表格表达完整；SVG 不含整张 PNG 嵌入。
