# HTX 背景素材库

仅在用户指定背景、提供相近参考，或基础全蓝背景缺乏层次时读取本文件。先分析文案，再从候选中选择一张；不要一次加载全部图片。

## 选择顺序

1. 用户明确指定的背景 ID 或参考图。
2. 内容类型与第一视觉层级：大数字、奖励金额、标题组或信息密集正文。
3. 文字安全区是否能容纳真实字体盒与 Logo。
4. 画布比例能否通过等比覆盖完成，且保留背景主要结构。
5. 局部文字对比度是否符合品牌规范。

候选未通过任一硬条件时排除。没有合格候选时回退到基础纯色、标准品牌渐变或蓝色 Hero + 白色内容区。

## soft-blue-white-01

- 文件：`assets/backgrounds/soft-blue-white-01.svg`
- 类型：柔和蓝白纵向渐变
- 颜色：顶部 `#FFFFFF`，底部 `#62A0FB`
- 推荐画布：方图、普通竖版；矢量资产可按目标尺寸直接渲染
- 适用：招募、社群、产品信息、标题与简短正文并存的海报
- 视觉重心：由标题、分割线和 `#0066FF` 核心数字建立
- 文字安全区：全画布内容安全区内均可排版；按局部背景亮度选择黑色或规范白色文字
- 避免：信息极少却使用高画布、在背景上叠加额外光柱或装饰纹理

## blue-grid-gradient-01

- 文件：`assets/backgrounds/blue-grid-gradient-01.png`
- 类型：蓝白栅格渐变与纵向光柱
- 原始尺寸：1080 × 1080
- 推荐画布：1:1 方图
- 适用：奖励金额、返佣比例、毕业礼金、大数字或单一核心利益点海报
- 主要视觉结构：右侧纵向栅格与模糊光柱；左侧相对平静
- 文字安全区：优先使用左侧约 55%；顶部深蓝区域使用规范白色文字，中下部浅色区域使用 `#000000`
- 避免：右对齐长文案、全宽表格、信息密集长图、在右侧光柱上堆叠正文
- 裁切：保持 1:1 时直接使用；其他比例只能等比覆盖并优先保留右侧光柱，禁止非等比拉伸

## 新增背景记录格式

每张新背景只新增一条记录，至少包含：唯一 ID、文件路径、类型、颜色、推荐画布、适用内容、主要视觉结构、文字安全区、避免场景和裁切规则。
