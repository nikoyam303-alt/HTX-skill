# HTX 火宝 Agent

把火宝作为独立视觉 Agent；把 `htx-brand` 作为排版与品牌规则的唯一来源。不要套用固定“副标题／主标题／日期”模板，也不要限制内容数量、海报类型、画布比例或火宝位置。

开始前定位本文件目录，以 `<skill-root>` 表示。参考资产从该目录读取。

## 工作流

1. 逐字锁定用户文案与指定尺寸；未指定尺寸时按 `htx-brand` 的内容密度规则选择。
2. 加载 `htx-brand`，先完成内容分组、信息层级和初步安全框。排版、字体、颜色、Logo、语义换行、信息承载与导出质检均以它为准。
3. 根据排版剩余空间反推火宝插画的姿态、朝向、道具和外轮廓；动作必须表达当前主题，不生成通用站姿填空。
4. 使用图像生成工具生成无文字、无额外 Logo、纯色绿幕背景的完整火宝素材；始终附 `<skill-root>/assets/htx-huobao-reference.png`。文案字面包含 `$` 且画面确需金币时，再附 `<skill-root>/assets/dollar-coin-reference.png`。
5. 本地去除绿幕并检查透明边缘。不要把生图背景直接当海报背景，避免模型生成的文字、符号和杂物混入成品。
6. 按 `htx-brand` 的动态版式合成最终海报。先锁定 Logo、文案与火宝安全框，再按真实内容调整字号、换行、留白和插画尺度；不得复用上一张海报的固定坐标。
7. 只交付通过品牌质检与火宝质检的最终图；发现问题时只修正对应层：插画问题重生或重抠，排版问题复用素材重排。

## 火宝生成约束

- 保持官方身份：蓝色双角、正确脸型、肤色与材质、蓝色 T 恤及胸前官方白色火焰标识。
- 双手、双腿和双脚必须是连续裸露的角色本体；提示词明确写出 `bare hands`、`bare feet`、`no gloves`、`no shoes`、`no shorts`。
- 姿态自然且服务主题，可用轻微三分之四视角；禁止极端俯视、仰视和越肩镜头。
- 完整保留角、脸、手势、关节和关键道具；不要用裁切掩盖错误肢体或服装。
- 禁止模型生成文字、字母、数字、额外品牌标识、网络节点、发光轨迹线、漂浮 UI 和无意义小图标。
- 仅当文案包含字面量 `$` 且金币有叙事作用时使用 1–2 枚金色浮雕美元金币；否则不加。
- 火宝和道具不得侵入已经规划的文案、Logo 或信息安全框。绿幕颜色不得出现在主体、服装、道具和辉光中。

## 透明素材与合成

- 默认生成纯色高饱和绿幕背景，主体边缘清晰且无绿色反光；用本地工具转为真透明 RGBA。
- 去背后放大检查角、手、脚、道具细边、半透明辉光与 T 恤标识；不得残留绿边、色块、背景文字或孔洞。
- 按初步安全框等比放置，不拉伸、不改色、不用二次放大掩盖低清晰度。
- 若插画轮廓与版式冲突，优先调整插画姿态或整体布局，不通过强行缩小标题、无提示断行或裁掉道具解决。

## 质检

除 `htx-brand` 的全部检查外，确认：

- 用户文案逐字完整；没有模型生成的额外文字或背景框。
- 主标题整组字号统一，换行由可用宽度与完整语义共同触发，不因预设模板无提示断行。
- 火宝身份、T 恤标识、裸手裸脚、动作与主题正确，关键外轮廓完整。
- 透明边缘干净；人物、道具与文字、Logo、信息区互不碰撞。
- 画面中的金币、符号和装饰均由内容触发，不为填空而添加。

通过后交付最终 PNG；用户要求时再提供可编辑文件。
